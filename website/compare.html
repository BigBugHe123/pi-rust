PICK RPI WHEN

什么时候选 rpi

  • 你要把 agent loop 放进自己的 Rust 程序，而不是驱动一个别人的 CLI。
  • 你关心进程边界：Rust 二进制、明确的 crate 分层、可替换的 Provider。
  • 你需要在无网络、无 API key 的环境里对 agent 循环写确定性的测试。
  • 你想要一个崩溃后可续跑、日志损坏能自愈的会话层。
LOOK ELSEWHERE WHEN

什么时候别选 rpi

  • 你只想装完就用，不想碰 Rust 工具链——直接用 Claude Code 或 Codex CLI。
  • 你要的是 IDE 里的补全和行内编辑，而不是一个 agent runtime。
  • 你需要成熟的云端沙箱和团队协作面板——OpenHands 更合适。
  • 你依赖某个特定厂商的账号额度与官方支持渠道。

先看它怎么分层，再决定要不要用。
